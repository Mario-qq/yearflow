# 个人主工作台（/desk）—— 规格与实施提示词 v1.4

> 定位：从 2026-10-16 起 YearFlow 升级为 **年度计划甘特图 + 个人主工作台** 两大核心模块。
> 甘特图管「这一年往哪走」，工作台管「今天、这周具体做什么」。
> 本文是工作台范围内的唯一事实来源（同 POMODORO_SPEC / ANNUAL_SPEC 的地位）；与 SPEC.md 冲突时，工作台范围以本文为准。
> **已拍板（2026-10-16）**：周历七张日卡 + 可切月历 · 紧急度三档 · 跟进**放在周历里**（点 @人 聚合），只分「待告知 / 待下发」· 没排日子的事叫「**待处理**」，平时收起 · 新建是右下角悬浮小按钮（`N`）· **挪动**靠拖动时浮出的小月历，不占主界面（§2.4）· 工作台数据全部上云、手机不显示 · 每天自动全库备份，可整库回滚。
> **W2 拍板（2026-10-16）**：学习目标 = AI 基础 / SAP / 英语（学习卡上 ⚙ 可改）· 每次学 30 分钟、短版 15 分钟 · 固定学习时间与最晚提醒由负责人自己设（默认不设 ⇒ 不提醒）· 桌面版关窗收进托盘、**默认不开机自启**（托盘/设置里可开）。
> **v3 拍板（2026-10-19，负责人反馈一轮）**：日卡自上而下 = 要事 → 学习（精简两行）→ 工作区 → 生活区 → 年度计划（底部、可收起、可选显示哪些）· 工作/生活用**非文字**区分（生活区 = 青色左条 + 极淡底；月历/抽屉里的生活行带同色左条）· 做完的**就地显示**不折叠（只有「不做了」收在卡底）· 周末默认收成窄条（工具条与窄条可展开，记在本机）· 标题自动换行 · 新建卡可直接点选 工作/生活 · 紧急度 · 重要 · 要事 · 哪天 · 新增三项方法：**要事**（Ivy Lee，每天 ≤3 件）、**重要**（艾森豪威尔第二轴）、**下班收尾**（Cal Newport shutdown）。细则见 §十一。
> **v3.1（2026-10-19，负责人反馈）**：学习卡挪到**头部**，在统计卡（本周 / 学习 / 里程碑）左边、同高并排，周历月历都看得到；日卡里不再放学习卡，今日脉搏里也不再重复「还没学」。卡片一律**不要左色条**：生活区、生活行只用极淡生活色底区分；学习卡只用淡淡的目标色底。头部左侧改为日历小牌（月份条 + 大号日期）+ 星期 / 第几周 / 今天进度细条 + 一排小药丸。窄窗时学习卡 + 统计卡整体折到下一行。
> **v3.2（2026-10-19）**：头部**一行到底、不折行**（≤100px）：日历小牌 + 星期/周次 + 单行脉搏药丸（放不下淡出）｜学习卡（先收窄、次要操作悬停才亮）｜统计卡。去掉头部的今天进度条。
> **v3.3（2026-10-19）**：要事可**拖动设置**——拖进某天要事区 = 设为那天要事（别的日子顺带挪过去，一步撤销）；拖回工作/生活区 = 移出；每天上限 3 件。空要事区平时藏着，拖动中露出。
> 版式以 `docs/desk/w0-prototype.html`（W0 原型 v2）为准；v3 的改动以 §十一 为准。

## 一、要解决的问题（负责人原话 → 设计回应）

## 二、主界面（布局 A 已定，细节以 W0 原型确认为准）

### 2.1 版式（W0 原型 v2）

```
┌ 顶栏（现有，加「工作台」导航） ─────────────────────────────────────────────────┐
│ 周五 · 第 42 周                                   ┌───────────────────────────────────────┐│
│ 10月16日                                          │◔52% 本周 16/31 ▂▅▃▆▁ │学习 ●●●○○│◆ 里程碑 │收尾本周→││
│ ● 还剩 1 件紧急  ● 张经理 那有 2 件要说  ● SAP 还没学 └───────────────────────────────────────┘│
│ ‹ 本周 10/12–10/18 ›  今天  [周|月]                                         [待处理 4] │
│ ┌12 周一┐┌13 周二┐┌14 周三┐┌15 周四┐┌──16 今天·周五──┐┌17 周六┐┌18 周日┐              │
│ │✓ 4 完成││✓ 4    ││✓ 3    ││✓ 4    ││ 学习卡          ││ 例行   ││ 例行   │              │
│ │已完成… ││       ││       ││       ││ 年度计划        ││ 事项   ││        │              │
│ │↻挂到今天││       ││       ││       ││ 例行 / 事项     ││        ││        │   (＋ 新建 N) │
└───────────────────────────────────────────────────────────────────────────────────┘
```

- **头部**：左边是日期 + 今日脉搏（一句话三件事，@人可点）；右边一张安静的统计卡：本周完成环 + 每天完成数小柱、学习 5 点、最近两个里程碑倒计时；周五 17:00 后 / 周末多出「收尾本周 · 剩 N 件 →」。
- **日卡**：七张圆角卡片（间距 8px），卡头 = 大号日期 + 星期 + 完成数 + 2px 完成进度线；今天的卡 2fr、主色描边光圈；周末有事 1fr、没事 0.7fr；过去的卡淡化（hover 复原），只显示已完成的前 4 条 +「还有 N 件已完成」+「↻ N 件没做完，挂到了今天」。
- **月历**（`[周|月]` 切换，`W` / `M`）：6×7 卡片格，每格显示前 3 件未完成 +「+N 件」，过去的格只显示 ✓ 完成数；格子之间可直接拖；点「周 ›」跳回那一周。偶尔看全月、远期排期用。
- **待处理**：工具条右侧按钮带件数角标，点开（`I`）从右侧滑出抽屉，平时完全不占位置；从抽屉拖到某天即排期，拖动时抽屉自动变淡让出视线。
- **新建**：右下角悬浮小按钮「＋ 新建 N」，`N` 或点击展开成一张输入卡（实时显示解析出的标签），回车创建、Esc 收起；不写日子默认今天，写「待处理」进待处理。

### 2.2 一天之内的分区顺序

1. **学习卡**（学完后收成一行「今天学过了 · 45 分钟」）
2. **年度计划**：甘特图当天应打卡的任务（复用 `derive/dayPanel.dayEntries`），一键打卡 / 开专注 —— 与甘特图联动的主通道
3. **例行**：今天该做的日常/周常/月常；漏做的周常在本周内、月常在本月内以「补做」挂在今天
4. **事项**：待办与跟进混排，按紧急度 → 截止日排；跟进行尾是 @人 小标签（头像色 + 名字 + 告知/下发）；过去没做完的顺延在最上方

分区标题 11px、空分区不渲染；行高 30px，左侧圆形勾选（紧急红圈、尽快橙圈），例行是方形勾选。

### 2.3 在哪里用

- 数据全部云同步；**工作台只在电脑宽度（≥768px）出现**：桌面版与电脑浏览器的默认首页都改为工作台，甘特图仍一键可达。
- 手机（<768px）底部导航不加工作台，默认落点仍是打卡页；手机直接打开 /desk 时跳回打卡页。
- 学习卡依赖的甘特任务、打卡、专注记录本来就同步，手机打卡页照常能打学习任务的卡。

### 2.4 挪动（重点功能，经常用，不占主界面）

**① 拖 → 浮出小月历（主路径）**
- 任意一行按住拖动 3px，右下角（新建按钮上方）浮出「挪到哪天？」小月历：从本周一起 5 周（本周 / 下周 / 后面三周），每格显示日期 + 已排件数的小点（红点 = 紧急），过去的日子不可落。
- 光标停在哪格，顶部实时写出「→ 下周三 · 10/21（已排 3 件）」；松手即排上、小月历消失；Esc 取消。底部一条「放进待处理」落区。
- 也可以直接落在周历的日卡或月历的格子上；多选时拖任意一行带走全部选中。

**② 选中 → 挪到…（键盘与批量）**
- `Ctrl+点` 逐个选、`Shift+点` 连续选；选中后底部浮出一条：**挪到…（D）· 明天 · 下周一（⇧M）· 下周同一天（⇧W）**· 紧急度 · 完成（X）· 不做了。「挪到…」弹出同一个小月历，点一天即可。一次挪动 = 一条撤销记录。

**③ 一天 / 一周的批量**
- 日卡右上角「⋯」：这天没做完的全部 → 明天 / 下周一 / 下周同一天，或「全选再自己挑」；同菜单里标休息日 / 补班日。
- 收尾本周（§6）：一键全部挪到下周一 / 按原星期挪，或逐条定去处。

**④ 规则与口径**
- 待办、跟进都能挪；例行事项可以「这一次改到某天」（只改这一次，规则不变，见 3.3）；甘特图的「年度计划」行不能在工作台里挪（改期回甘特图拖 bar）。
- 每次「往后挪」`deferCount + 1`（往前挪不加）；拖延信号用它（§3.1）。
- 挪动只改 `date`，不碰紧急度与截止日；挪到截止日之后时提示一次、截止日标红。

## 三、四类事项的规格

### 3.1 待办（WorkItem.kind = 'todo'）

- 字段：标题、备注（可选）、紧急度、排期日 `date`（缺省 = 待处理）、截止日 `dueDate`（可选）、范围 `scope`（工作/生活）、关联目标 `goalId`（可选，仅作标签与筛选）。
- 紧急度三档：🔴 紧急（今天必须）/ 🟠 尽快（本周内）/ ⚪ 普通。截止日 ≤ 明天的事项至少按「尽快」显示、已过截止日按「紧急」显示（只影响显示，不改数据）。
- 状态：open / done / dropped（「不做了」与「做完了」分开，周末小结里分别计数）。
- 拖延信号（小巧思）：同一待办被往后挪 ≥3 次（`deferCount`）或过期顺延 ≥3 天，行尾出现淡色提示「拆小 · 改期 · 删掉 · 转跟进」，点一下即执行，不弹窗。

### 3.2 跟进（WorkItem.kind = 'followup'）

- 字段：在待办基础上加 `person`（对象，输入时按历史出现频率自动补全）、`mode`：**待告知 / 待下发**（不做「等回复」）。
- **不单独成栏，排在周历上**（负责人 2026-10-16 拍板）：跟进本质是「哪天要去说/发」的事项，和待办同一套排期、顺延、挪动；没排日子的进待处理。
- 「按人聚合」靠点击实现：点任何 @人 标签（或今日脉搏里的人名）浮出人物卡——TA 的全部未完成跟进（告知/下发、哪天）、最久挂了几天，周历里同时高亮 TA 的事项、其余淡化。
- **复制给 TA**（小巧思）：人物卡里一键生成可直接贴进聊天工具的文字：「张三，同步几件事：1. … 2. …」；「全部标为已说」一键完成。

### 3.3 例行（Routine + RoutineLog）

- 规则：每天 / 每个工作日 / 每周几（多选）/ 每月几号（含「月末」）/ 每月第 N 个周几；可选时间点（只用于排序与提醒）、起止日期、暂停。
- 范围：**工作**（只在工作日出现，遵守休/班标记）/ **生活**（每天都按规则出现）。
- 完成记录 `RoutineLog.id = routineId + ':' + date`（确定性 id ⇒ 两台设备同时勾选不会出两条）。
- 漏做：日常不补；周常挂到本周日；月常挂到月底；「跳过」与「完成」分开记。
- 本次改期：某一次例行可以挪到别的日子（如这周三的周报改到周四），记一条 `RoutineLog{status:'moved', movedTo}`，原日不再显示、新日期出现一次，完成记在原日那条上；规则本身不变。
- 休/班标记 `DayMark`：周历列头右键「标为休息日 / 补班日」。不内置节假日表（2027 年安排尚未发布，手动标两次比维护一张表可靠）。**只影响工作台**，不改甘特图 `weekdays` 规则的口径。

### 3.4 快速添加（一句话建任何东西）

右下角悬浮按钮展开的输入卡，`N` 打开，回车创建、Esc 收起，下方实时显示解析出的标签（纯函数 `parseQuickAdd`，vitest 覆盖）。界面上不放写法示例，写法只在按钮的悬停提示里：

| 写法 | 结果 |
|---|---|
| `!` / `!!` | 尽快 / 紧急（缺省普通） |
| `@张三` | 变成跟进，对象张三；含「下发/发给/分派」为待下发，否则待告知 |
| `今天` `明天` `后天` `周三` `下周一` `10.20` `10-20` | 排期日（不写 = 今天；写 `待处理` = 不排日子） |
| `截止周五` `ddl 10.31` | 截止日 |
| `#SAP` | 关联目标（按目标名模糊匹配） |
| `每天` `工作日` `每周一三` `每月5号` `每月最后一天` | 变成例行 |
| `~生活` | 范围=生活（缺省：工作日为工作、周末为生活） |

### 3.5 交互与键盘

- 勾选：圆圈填充 + 行淡出滑入「已完成 N」折叠（140ms，统一缓动，减弱动效时直接切换）。
- 拖拽：原生 pointer events，3px 起拖，拖动中只改 transform；落点 = 日卡 / 月历格 / 浮出的小月历 / 「放进待处理」（§2.4）。
- **编辑卡**（W2 补，2026-10-16）：行右键「编辑…」或选中一件按 `Enter`：标题、待办/跟进（对象按历史频率补全、告知/下发）、紧急度、哪天做（可放回待处理）、截止、目标、范围、备注；「保存」= 一条撤销记录，改排期按挪动口径计 `deferCount`；编辑卡开着时点外面不收（防丢字），Esc/取消放弃。例行同样有编辑卡（标题、五种规则、时间、范围、起始日、备注）。
- **例行管理**：待处理抽屉加「例行」页——全部例行（含暂停的）、新建、编辑、暂停/恢复、删除；暂停的例行周历上不出现，只能在这里恢复。一句话新建例行可带时间（`每周一 9:00 提交周报`，只在例行里认）。
- 「不做了」的事项折在当天「已完成 · 不做了 N」里，展开再勾一次回到未完成（不计入完成数）。
- 键盘：`N` 新建 · `I` 待处理 · `W`/`M` 周/月视图 · `←/→` 翻周/翻月 · `T` 今天 · `S` 开始学习 · 选中后 `Enter` 编辑 · `D` 挪到… · `Shift+→` 往后一天 · `Shift+W` 下周同一天 · `Shift+M` 下周一 · `X` 完成 · `1/2/3` 紧急度 · `Esc` 取消。全部操作进 undo 栈，`Ctrl+Z` 可撤。
- 命令面板（已有）加入工作台命令。

## 四、和甘特图怎么关联（负责人问 #14 的建议）

**做（有真价值、零重复数据）**
1. **今日「年度计划」分区** = 甘特图当天应打卡任务，打卡/专注结果直接回写甘特点阵。工作台成为甘特计划的每日执行入口，不新增任何数据。
2. **学习卡的内容取自甘特图的学习任务**：甘特任务的打卡规则（如 SAP 一三五、AI 二四）就是学习排程，不在工作台另建一套。
3. **里程碑倒计时**：头部统计卡显示最近 1–2 个未达成里程碑「还有 N 天」——保留你说的「时间观念和紧迫感」。

**可选（只当标签）**：待办 `#目标` 仅用于筛选与显示，**不计入甘特进度**（避免两套口径打架）。

**不做**：待办自动生成甘特 bar；工作台数据进年报。

## 五、学习防忘：六层机制（负责人问 #7）

科学依据：执行意图（Gollwitzer，「如果…就…」计划让执行率显著提高）、习惯锚定、「绝不连断两天」、降低启动门槛。

| 层 | 机制 | 落地 |
|---|---|---|
| 1 | **固定锚点** | 设置「我会在 [午饭后 12:30] 学习」，学习卡第一行就是这句话（可按星期分别设） |
| 2 | **到点提醒** | 到点未开始 → 桌面系统通知；最晚时间（如 21:00）仍未学 → 第二次提醒「15 分钟也算」。**需要桌面版常驻**：关窗改为收进托盘 + 可选开机自启 |
| 3 | **首屏醒目** | 没学之前学习卡置顶、主色描边轻呼吸（减弱动效时静态）；学完收成一行 |
| 4 | **一键开始** | 「开始 45 分钟」直接起番茄钟并绑定当天的学习任务，结束自动打卡（复用现有结果卡）；另有「只有 15 分钟？开始短版」 |
| 5 | **不连断两天** | 昨天断了 → 今天卡片文案变成「昨天断了一天，今天别连断」 |
| 6 | **周目标代替日完美** | 显示「本周 3/5 天」环，周末可补，避免一次断掉就放弃 |

今天学什么：当天应打卡的学习任务里，按「进度落后最多 → 最久没碰」排第一，点一下可换下一个。哪些目标算「学习」在设置里勾选（如 AI、SAP、Python）。

学习完成的口径：当天学习类任务的专注净时长合计 ≥ 每日目标分钟数，或手动打卡「完成」。

**W2 落地口径（2026-10-16，`lib/derive/study.ts` + 单测）**
- 某天「学过了」= 学习目标有一条「完成 / 做了一点」打卡，**或**学习目标的专注净时长 ≥ 短版分钟数（「15 分钟也算」）。周点阵、连学天数、「昨天断了」都按这个口径。
- 学习任务的专注**跑到计划终点**⇒ 自动打卡：当天学习专注合计 ≥ 每次学习分钟数记「完成」，否则「做了一点」；已有「完成」不动、「做了一点」只升不降。提前「结束并打卡」= 按实际时长记一段专注 + 打「完成」。桌面版小窗里结束的那段由主窗口代打卡（小窗的内存 store 不回写主窗口）。
- 「昨天断了」只在昨天**排了**学习却没学时出现；没排学习的日子不断连学天数。
- 学习卡推荐的那个任务不在「年度计划」分区重复出现，学过之后回到年度计划显示已打卡。今天没排学习 ⇒ 一行「今天没排学习 · ▶ 想学就学」；没设学习目标 ⇒ 一行引导。
- 提醒：只在桌面版主窗口跑（每 30 秒判一次；睡眠唤醒立刻补判）；今天排了学习、还没学、没在学 ⇒ 到固定时间提醒一次，到最晚时间再提醒一次「15 分钟也算」；过了最晚时间才打开只补最晚那次；每天每种最多一次。点通知 → 主窗跳到工作台。锚点可按星期覆盖（时间/地点/这天不提醒）。
- 托盘：关主窗 = 隐藏（渲染进程照常跑提醒与计时），首次收进托盘弹一次说明；托盘菜单：打开 · 开始学习 · 关窗时收进托盘 · 开机自启（`--hidden` 静默进托盘）· 退出；Windows 注销/关机时放行关闭。偏好存本机 `userData/shell-prefs.json`，不进备份、不同步。

## 六、小巧思清单（每条都要真有用，不做装饰）

1. **今日脉搏**：一句话说清今天的局面（紧急几件、谁那有事要说、学没学），不是一排数字。
2. **复制给 TA**：跟进按人一键生成可粘贴的消息。
3. **本周开局**（周一首次打开）：上周没做完的 N 件 →「全部带到本周 / 逐条处理」。
4. **收尾本周**（周五 17:00 后 / 周末，头部统计卡多出入口）：弹出一张收尾卡——标题一句话（「这周干得不错，还剩 N 件要安排」）+ 四格大数字（完成 · 跟进说完 · 学习天数 · 挪过 ≥3 次）+ 每天完成数柱图 + 剩下的逐条四选一（下周同一天 / 下周一 / 待处理 / 不做了）或一键全挪；「复制本周小结」是二期周会素材的来源。
5. **拖延信号**：顺延 ≥3 天的待办给出「拆小 / 改期 / 删掉 / 转跟进」。
6. **清空当天**：今天的事全部处理完，列底浮现一行安静的「今天清空了」。
7. 深色主题一等公民，数字 `tabular-nums`，动效只留功能性的。

## 十一、v3（2026-10-19）：精简 + 三项方法

**负责人原话 → 落地**
1. 「右上角三块不错；学习卡小一点、简洁一点」→ 头部统计卡不动；学习卡两行：`▶ 目标 · 任务 · 周点阵` / `锚点时间 · 为什么 · 15 分钟 · 换一个 · 已学过 · ⚙`，左边一道目标色，去掉呼吸描边。高度 ≈ 58px（原 ≈128px）。
2. 「新建不能像例行一样选日常/工作、紧急；鼠标点新建没反应」→ 新建卡下方两排点选：工作/生活 · 紧急/尽快/普通 · ★ 重要 · ◎ 要事；今天/明天/待处理 · 挑日子。点选 > 一句话里写的 > 日卡「＋」预填 > 默认（周末默认生活）。点选按钮不抢输入框焦点。
   「没反应」根因：根节点的「点空白收浮层」在冒泡阶段把刚被按钮打开的浮层当旧的关掉（键盘 N 不经过这条路）。改为：捕获阶段记下点击前已开的浮层，冒泡时只收这些（同时修好头部点 @人 打不开人物卡）。
3. 「工作和生活要可视化区分，非文字；年度计划拖到最下面；甘特图不是所有当日任务都要显示」→ 两区见上；年度计划放卡底；「选择显示」浮层按目标（含以后的任务）或按任务勾选，行右键「不在工作台显示」；只影响工作台，存本机设置 `desk.planHiddenGoals / planHiddenTasks`。工作/生活区都是拖放目标：拖进另一区 = 改范围（同一天换区只改范围，一条撤销）。
4. 「已完成不要单独一块默认隐藏」→ 做完的留在原区里打勾、不划线、只淡一档；过去的日子全部列出（不再只露 4 条）。「不做了」仍收在卡底。
5. 「周六日少用，给周一~周五腾地方；默认换行」→ 周末默认收成 40px 窄条（日期 + 没做件数，仍可拖入，点一下展开）；今天正好是周末则那天照常展开。今天列宽 1.7fr。标题 `overflow-wrap: anywhere` 换行，标签放不下时掉到下一行靠右。

**三项方法（负责人选了做）**
- **要事**（Ivy Lee）：`WorkItem.focusOn = 那天`，每天最多 `MAX_FOCUS = 3`（做完的也占位）。今天卡顶「要事」区；没挑时一行「挑今天最要紧的 3 件」→ 浮层点 ☆。右键 / 选中条 / `F` 设为或移出（按事项各自的日子：以后的 = 那天，今天/顺延/待处理 = 今天）。头部脉搏「要事还剩 N / M」。
- **重要**（艾森豪威尔）：`WorkItem.important`，与紧急度独立；同紧急度里重要的在前；行首小星 + 标题加粗。一句话里独立的 `*` / `★`；右键、选中条、`*` 键切换。
- **下班收尾**（Cal Newport）：工具条「收尾今天」/ 到点头部「该收尾了」/ 桌面版到点通知（每天一次，点开 `/desk?shutdown=1` 直接开面板）。三步：今天做完了什么 → 没做完的逐条给去处（下个工作日 · 挑日子 · 待处理 · 不做了 · ✓）或「全部挪到下个工作日」→ 挑下个工作日的要事。「收工」记本机，当天不再提醒。时间 `desk.shutdownAt`（默认 17:30，'' = 不提醒，面板底部可改）。不收尾也照旧自动顺延。

**数据**：`WorkItem.important?`、`WorkItem.focusOn?` 都是可选字段，老数据零迁移；云端 `work_items.data` 是 jsonb，无需改表；备份 zod 已加。派生纯函数 `isFocusOn / nextWorkday / shutdownDue`，计划 `planSetFocus / withScope`，均有单测。
