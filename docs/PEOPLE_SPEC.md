# 人际模块（/people）—— 规格 v1（2026-10-19）

## 一、要解决的问题

负责人原话：「有个待与人沟通交际的模块……增强我在人际方面的能力……我逻辑思维强，但日常沟通、准备惊喜等感性思维或沟通情商不够。」

**设计回应**：不靠临场发挥，把「情商」拆成逻辑型的人也能执行的流程——**到点提醒 + 结构化记录 + 提前倒推**。v1 范围经负责人确认：人物档案 + 联系节奏、一句话记互动、重要日子倒推计划（沟通准备卡、每周小技能留到以后）。

## 二、方法出处

| 做法 | 出处 | 落在哪里 |
|---|---|---|
| 了解对方的世界（近况、在意的、怕的） | Gottman「爱的地图」 | 档案：近况（互动记录里的「新知道的事」）、背景、喜好 / 避开 |
| 给每个人定联系节奏，主动维护 | Ferrazzi《别独自用餐》/ Personal CRM | `cadenceDays`，超了在工作台头部提醒 |
| 心意按对方在意的方式表达 | Chapman《五种爱的语言》 | 档案可选 1–5 种，第一个最重要；准备待办的备注里给出「怎么做」 |
| 没话题时 | FORD（Family / Occupation / Recreation / Dreams） | 「记一笔」底下的提示 |
| 被记得是最好的礼物 | —— | 送礼点子池：TA 随口提过的，马上记下 |

## 三、界面

- **入口**（负责人 10-19 二轮：不放工作台主体、太显眼）：工作台工具条「收尾今天」左边一个小按钮「人际」，角标 = 需要关注的人数（14 天内有重要日子 / 超了联系节奏，同一个人算一次，琥珀淡底、不用强调色）；点开是弹窗（lazy 分包，Esc / 点外面 / × 关）。顶栏不再有单独的页面，头部也不再有人际药丸。
- **弹窗**：左栏 = 回车建档 + 搜索 +「需要关注」（30 天内的日子、超了节奏的人，一人一行合并显示）+ 按关系分组的全部人 +「工作台 @人 里还没建档的」一键建档（默认同事）。右栏 = 选中那个人：抬头（改名 / 关系 / 联系节奏 / 上次联系）→ 记一笔 → 左：近况、互动记录；右：重要日子（公历 / 农历、起始年算岁数 / 周年、提前准备开关）、爱的语言、喜好与避开、送礼点子池、要跟 TA 说的（@人 跟进）。没选人时显示「三件小事」说明 + 30 天内的日子。
- **人物卡**（工作台点任何 @人）：建过档的多一段摘要（关系 · 上次联系 · 快到的日子 · 看重什么 · 最新近况）+「记一笔」（紧凑版）+「打开档案 →」（开人际弹窗并选中 TA）；没建档的给「＋ 建档」。

## 四、规则

- **名字即关联**：`Person.name` 与 `WorkItem.person` 同口径；改名时 TA 名下**没做完的** @人 跟进一起改名（一条撤销）。
- **上次联系** = 互动记录最晚日期 与 TA 名下做完的 @人 跟进（`doneAt` 的本地日期）取较晚者。没联系过从建档那天算。
- **重要日子下一次**：公历 2/29 平年落 2/28；农历闰月按平月过，没有三十按廿九。农历用查表法（`lib/lunar.ts`，1900–2100，单测逐日对照 lunar-javascript 覆盖 1901–2099 全部日期；**不用** Intl 中国历法——它在 2027、2030 春节都差一天）。
- **倒推准备**：重要日子进了 14 天窗口（且没关「提前准备」、当天之前）⇒ 自动生成 3 件待办：14 天前「想想 X 准备什么」、7 天前「把 X 的礼物 / 安排定下来」、1 天前「明天 X：写几句具体的话」；已过的步骤排今天，同一天撞上的合成一步。截止 = 前一天；同事 / 上级的放工作区，其余生活区；备注带爱的语言、喜好、避开、没用过的点子。id 确定（`prep-人-日子-那次日期-步`），档案 `prepared` 记下「这次已生成」⇒ 删掉生成的待办也不会再生成；本次打开内另有一层去重。
- 工作台打开时与跨午夜时判一次。

## 五、数据

`Person`、`Interaction`（domain.ts），云端表 `people` / `interactions`（`supabase/migrations/0006_habits_people.sql`，与习惯两张表同一个迁移）。派生 `lib/derive/people.ts`（11 个单测）、`lib/lunar.ts`（8 个单测，含逐日对照）。写操作 `store/peopleActions.ts`，全部进撤销栈。自查 `scripts/check-people.mjs`。
