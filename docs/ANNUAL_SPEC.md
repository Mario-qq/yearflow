# ANNUAL_SPEC — 年报规格书 v2（2026-10 重构）

> `docs/SPEC.md` 的扩展章节，年报范围内以本文档为准。
> v1（11 个 beat 的叙事长图 + 长图导出 + 打印）已整体删除重做，原因见 `docs/PROGRESS.md`「年报 v2」一节。

---

## 一、定位

`/year` = **一页海报长卷**：封面 + 四节 + 结尾。一眼看懂「这一年过成了什么样」，好看到愿意时不时打开。

| 页面 | 回答的问题 |
|---|---|
| `/review` 复盘（仪表盘） | 这个月 / 这一年的数字是多少 |
| **`/year` 年报（叙事）** | **这一年过成了什么样** |

三条设计原则（负责人 2026-10-11 拍板）：

1. **一节 = 一句话 + 一张图**。不写口径注释、不写「左列 = …」式的图例说明。数字的细节放进悬浮提示。
2. **没内容的节整节不出现**，编号按实际出现顺序排；整区间零数据走空态。不显示一堆 0。
3. **有仪式感**：大字号、目标色做主角（封面光晕与年份渐变取投入最多的三个目标色，每个人的年报颜色不同）、入场动效；但颜色/字号只走令牌，并完整尊重 `prefers-reduced-motion`。

## 三、页面结构

| 块 | 标题句（规则驱动） | 图 |
|---|---|---|
| 封面 | 「这一年，你把 N 小时交给了 M 个目标。」+ 三个数：打卡天数 / 投入小时 / 里程碑达成 | **年轮**：区间每天一根放射刻度，长 = 当日活动强度，色 = 当日主角目标；未到的日子画虚；圆心显示已走过百分比 |
| 01 时间去哪了 | 「X 拿走了最多的时间：h 小时，占 p%」 | 按目标分段的总条 + 每目标一卡（小时、占比、逐月迷你柱）；未归类专注单列灰色 |
| 02 坚持 | 「N 天留下了打卡，最长一口气连续 K 天」 | 区间打卡热力图（底部括号标出最长连续段）+ 各目标最长连续落在时间轴上的哪一段 |
| 03 收获 | 「抵达了 N 个里程碑，完成 M 个目标」 | 里程碑时间轴 + 清单（达成 / 已过 N 天 / 还有 N 天）+ 每目标结局卡（进度环 + 已完成/进行中/已停 N 天/随缘） |
| 04 节律 | 「X 月是状态最好的月份，完成率 r%」 | 逐月投入柱（按目标堆叠，下挂完成率与月度复盘自评 ★）+ 星期×小时专注时段 |
| 结尾 | 进行中：「2026，还剩 N 天。」/ 已走完：「…，写完了。」 | 已走过进度条 |

## 四、派生层：`src/lib/derive/annual.ts`

页面只调 `annualIndex()` 一次（一个 `useMemo`），各节组件只读 props。

| 函数 | 口径 |
|---|---|
| `rangeOf` | 整月对齐；`clippedEnd = min(end, today)`；看未来区间时 `clippedEnd < start` ⇒ 自然归零 |
| `investedOf` | 逐目标逐月调 `effectiveMsByGoalPrefix`（与复盘页同一口径，单测锁定逐月取整 = `minutesByGoalByMonth`）；未归类会话单列；`share` 分母含未归类 |
| `dailyCells` | 打卡分 = 各目标当日最强记录 done=1/partial=0.5 求和（= 复盘页 `dailyActivityScores`）；主角目标 = 打卡分 + 专注小时 最大者（只用于上色） |
| `longestActiveSpan` | 连续有打卡的自然日段（热力图上画得出来的那串） |
| `longestRunOf` | 各目标最长连续，口径 = `calcStreak`（单测锁定相等） |
| `goalOutcomes` | completedAt / 全部任务 done ⇒ 已完成；未完成的全是随缘 ⇒ 随缘；非免打卡空窗 > 30 天 ⇒ 已停；否则进行中。归档与软删的目标不列 |
| `milestoneStats` | 兑现率分母只算已到期（`date ≤ clippedEnd`）的；还没到日子的不算失败 |
| `monthProfiles` / `bestMonth` | 合计完成率 Σscore/Σscheduled；最佳月只在已过完的月份里评；附带月度复盘自评 |
| `focusByHourDow` | 区间归属看 `date`，钟点/星期看 `startAt` 本地值 |

归档目标照常进年报的投入与逐日数据（年报是历史，抹掉会让占比加不到 100）；只有软删的不算。

## 五、视觉与动效

- 新令牌：`--radius-xl`（海报面板）、`--font-24`（标题句移动端）、`--font-display`（封面年份，clamp 88–160px）。几何常量全在 `annual/constants.ts`。
- 文字一律文字色，目标色只出现在色点、刻度、条与格子上。
- 入场：每节滚入视口时淡入上移；年轮逐根生长、总条从左展开、热力/时段格逐列淡入、月柱长高、进度环描出、封面数字滚动。全部写在 `@media (prefers-reduced-motion: no-preference)` 里。
- ⚠️ 错开延迟一律用 `--d` 变量挂在**具体属性**的 transition 上，禁止内联 `transition-delay`：后者配上默认 `transition-property: all`，减弱动效时连换深浅主题的颜色都会被逐格拖慢（实测踩到，验收脚本有回归断言）。
- 悬浮提示：全页一个 `Tip`，图元素只挂 `data-tip`，根节点事件委托；触屏轻点即显示。

## 六、性能

生产构建 + 压力数据（10 目标 × 8 任务 × 全年打卡 + 800 会话）：`/year` 首屏 < 500ms，区间切换重算 < 500ms，甘特首屏不回退（< 1s）。复测：`npx vite build && npx vite preview --port 4173`，再 `node scripts/perf-annual.mjs`。
